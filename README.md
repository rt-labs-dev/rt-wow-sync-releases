# rt-wow-sync

Your World of Warcraft addon settings, keybindings and macros, the same on every PC. Optionally your addons too. For Windows and macOS.

**Download, features and privacy policy: [apps.rtobo.dev/rt-wow-sync](https://apps.rtobo.dev/rt-wow-sync/)**

This repository holds the published installers under [Releases](https://github.com/rt-labs-dev/rt-wow-sync-releases/releases) and is the place to [report a problem or suggest something](https://github.com/rt-labs-dev/rt-wow-sync-releases/issues). The source code is not public.
